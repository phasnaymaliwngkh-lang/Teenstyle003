# src/components/ui

คอมโพเนนต์พื้นฐานจาก **shadcn/ui** — ตั้งค่าไว้แล้วใน [../../../components.json](../../../components.json)

เพิ่มคอมโพเนนต์ด้วย (รันใน `frontend/`):

```bash
npx shadcn@latest add button card input dialog
```

ไฟล์ที่ได้จะถูกวางไว้ในโฟลเดอร์นี้และแก้ไขได้เอง (shadcn คัดลอกโค้ดให้ ไม่ใช่ dependency)
สีทั้งหมดต้องอ้าง design token ใน `src/app/globals.css` เท่านั้น
