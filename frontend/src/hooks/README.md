# src/hooks

Custom React hook ที่ใช้ร่วมกันหลาย feature (hook ที่ใช้เฉพาะ feature เดียวให้อยู่ใน `features/<name>/hooks/`)

ที่จะเพิ่ม: `use-debounce.ts` (STEP 45 search), `use-media-query.ts` (STEP 31 responsive),
`use-local-storage.ts` (STEP 9 guest cart — ต้องครอบ try/catch), `use-camera.ts` (STEP 17 barcode scanner)
